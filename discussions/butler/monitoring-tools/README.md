# Monitoring-Tools — Prometheus, Grafana & Alternativen für Butler

**Erstellt:** 27.05.2026 · **Zuletzt aktualisiert:** 27.05.2026  
**Status:** 0 erledigt · 3 offen

Aktuell haben wir SAR (sysstat) für historische System-Metriken — zeichnet alle 10 Minuten CPU/RAM/Swap auf. Das war hilfreich um den OOM-Freeze nachzuvollziehen, aber die Auflösung ist grob und es gibt keine Warmmeldungen bevor was passiert.

Diese Sub-Diskussion erklärt oberflächlich, was Prometheus, Grafana und Alternativen wie Netdata sind — und wie sie uns beim Butler konkret weiterhelfen könnten.
