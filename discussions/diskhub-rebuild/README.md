# DiskHub — Portal-Rebuild

**Erstellt:** 21.05.2026 · **Zuletzt aktualisiert:** 26.05.2026  
*Status wird dynamisch aus den Sub-Diskussionen aggregiert (#48)*

DiskHub in seiner aktuellen Form wurde in einer Explorationsphase gebaut. Das UI ist komplex, die Datei-Struktur unklar und die Trennung von Blöcken und Sub-Diskussionen existiert nur implizit. Dieses Projekt dokumentiert den geplanten Umbau zu einer klareren Architektur.

**Sub-Diskussionen:**
- 📂 `offene-umbauplaene/` — Konkrete Umbau-Pläne (alle erledigt, als Textboxen dokumentiert)
- 📂 `diskhub-regelwerk/` — Abgeschlossene Architektur-Entscheidungen und Regeln (aus `offene-umbauplaene/` ausgegliedert)
