# Header-Box mit weißem Hintergrund + Trennlinien

**Erstellt:** 21.05.2026 · **Status:** ● offen

**Problem:** Der obere Bereich der Hauptdiskussion (Header / README) hat keine visuelle Abgrenzung — alles fliegt auf dunklem Hintergrund.

**Lösung (3 Sub-Punkte in einem, weil gleicher Bereich):**

**1. Weiße Box um Header + README**
- Helle / pastel-weiße Hintergrundbox um den gesamten Header- und README-Bereich der Hauptdiskussion
- Titel (markant), Zusammenfassung (Haupttextkörper) innerhalb der Box

**2. Fußzeile der Box**
- "Erstellt", Anzahl Sub-Diskussionen, "zuletzt aktualisiert" — alle diese Fußzeilen-Elemente
- Etwas dunkleres Weiß als der Box-Hintergrund (weil "unwichtigere Infos")

**3. Trennlinien**
- Vor dem Inhaltsverzeichnis (nach der Header-Box) = Trennlinie
- Nach dem letzten Element des Inhaltsverzeichnisses = Trennlinie

**Offene Fragen:**
- Welche konkreten Farben? (z.B. Box: #f8fafc / Footer: #e2e8f0 / Trennlinie: #cbd5e1)
- Soll bei allen Diskussionen gleich sein oder nur bei Haupt-Diskussionen?
