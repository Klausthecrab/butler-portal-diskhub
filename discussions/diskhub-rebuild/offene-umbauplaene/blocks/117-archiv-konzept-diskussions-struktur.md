### Archiv-Konzept — Diskussions-Struktur
*— · 27.05.2026*

**Problem**
Es fehlt ein klares Struktur-Konzept für Diskussionen: Titel/Frage, Offene Punkte, Archiv/Entscheidungen, Status quo und Human-readable-Kurzfassung.

**Lösung**
Die README soll als zentrales Element dienen:
- **Titel / Grundsätzliche Fragestellung**
- **Offene Punkte**
- **Archiv / Entscheidungen** — neue Kategorie
- **Status quo / Anleitung/Erklärung** — bei offenen Punkten: aktueller Stand. Ohne offene Punkte: Nutzungsanleitung
- **Human-readable Kurzfassung** — für Rückkehrer nach langer Zeit

Prüfen: Ist die README bereits der Kern und muss nur besser definiert werden?
