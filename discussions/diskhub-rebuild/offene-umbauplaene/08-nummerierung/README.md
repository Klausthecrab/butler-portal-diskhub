# Sub-Diskussionen nummerieren

**Erstellt:** 21.05.2026 · **Status:** ● offen

**Problem:** Die 6 Sub-Diskussionen unter "Offene Umbaupläne" haben keine konsistente Adressierung. Für Feedback/Diskussion sollen sie via Nummer referenzierbar sein.

**Lösung:**
- Die bestehenden Sub-Diskussionen (01–06) erhalten in ihrer Titelzeile innerhalb der index.md eine sichtbare Nummer
- Vorschlag: `#01: Datei-Struktur`, `#02: UI-Struktur`, `#03: Detail-Ansicht` usw.
- Die neuen Subs (07–10) haben dann logisch `#07:` usw.
- Nummer = Ordnername (zweistellig), direkt im ### Sub:-Title

- Nummer im index.md-Titel oder auch im Ordner-/Diskussionsnamen?
